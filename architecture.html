3. Moteur de Calcul engine.js

Fonction pure computeAll(scenario) qui retourne l'état complet du modèle financier.

Structure du Financement

Coût Total
totalProjet = budget_TTC + ameublement (11 × 40K) + coût_net_éco
MDM Invest (remboursement MRE)
subventionMDM = min(totalProjet × 10%, 5 000 000)
Remboursée à l'investisseur — ne réduit PAS le financement bancaire
Investissement Net
investissementNet = totalProjet − subventionMDM
apportTerrain = coût_terrain + frais (2 449 500 MAD)
apportNet = apportTerrain − subventionMDM ← capital réellement immobilisé
Montant à Financer
montantAFinancer = totalProjet − apportTerrain
Répartition 50/50 : Tamwilkom + Banque classique

Projections sur 20 ans

Pour chaque année y (1 → 20) :

revBrut    = (studios × prixStudio + lofts × prixLoft) × 365 × occ × (1.03)^y
revDeclare = revBrut × (1 − partInformel)
revTotal   = revDeclare + loyerCommercial × 12

charges    = gestion + salaires + utilities + entretien + ...
              (indexées 3%/an)

cashFlowNet = revTotal − charges − debtService − IS
cumulCF     += cashFlowNet

KPIs Financiers

KPIFormule
Rendement BrutrevBrut_an1 / totalProjet
Rendement Net / ProjetCF_net_an1 / totalProjet
Rendement Net / ApportCF_net_an1 / apportNet
DSCR(CF_avant_dette) / (service_dette_an1)
Paybackannée où cumulCF ≥ apportNet
Cash-on-CashCF_net_an1 / apportNet
Break-Even Occ.charges_fixes / (revBrut / occ)

TRI et VAN (avec valeur résiduelle)

Valeur Résiduelle (sortie fictive à l'an 20)
valeurResiduelle = totalProjet × (1 + 3%)^20
Appréciation du bien entretenu — même taux que la croissance des tarifs
TRI (IRR)
flux = [−apportNet, CF1, CF2, ..., CF19, CF20 + valeurResiduelle]
Newton-Raphson (100 itérations, tol = 10−7)
VAN (NPV) — taux 8%
VAN = −apportNet + Σ (CF_t + [valeurResiduelle si t=20]) / (1.08)^t

Création de Richesse

Wealth Creation (20 ans)
wealth = cumulCashFlow_20ans + valeurResiduelle − apportNet

Analyse de Sensibilité

6 variables testées à ±10% et ±20% : occupation, prix studio, prix loft, charges, taux banque, loyer commercial. Impact mesuré sur le cash-flow net année 1.

6. Orchestrateur app.js

Pipeline de rendu

recalc(scenario)
  → computeAll(scenario)    // engine.js
  → renderAll(state)        // render.js (14 sections)
  → updateAllCharts(state)  // charts.js (8 graphiques)
  → updateControlPanel()    // sync sliders/inputs

Gestion d'état

VariableRôle
currentScenarioScénario actif (prudent → optimiste)
currentViewVue active (overview, budget, cashflow, ...)
currentStateDernier résultat de computeAll()
customOverridesnull = préset | objet = paramètres custom

NiveauParamètres

8. Glossaire Financier

TermeDéfinition
apportNetCapital réellement immobilisé par l'investisseur = terrain − MDM cashback
MDM InvestSubvention marocaine pour MRE : 10% du projet, remboursée à l'investisseur (pas à la banque)
DSCRDebt Service Coverage Ratio — capacité à servir la dette (≥1.5x = confortable)
TRITaux de Rendement Interne — rendement annualisé incluant valeur résiduelle
VANValeur Actuelle Nette — création de valeur actualisée à 8%
TamwilkomProduit de financement participatif (mourabaha) de la CDG
Go SiyahaProgramme Maroc PME pour le tourisme — volet croissance verte
Surface utileIntérieur + 50% terrasse (convention marocaine)
Wealth CreationCumul CF 20 ans + valeur résiduelle − apport net
